# Мультимедийное занятие «Компьютерная графика: растровая и векторная»

**Предмет:** информатика  
**Класс:** 7  
**Уровень:** базовый  
**Тип занятия:** урок открытия нового знания  
**Продолжительность:** 45 минут

---

## Пояснительная записка

Занятие разработано с использованием мультимедийных ресурсов образовательных платформ (РЭШ, ИнтернетУрок, ЯКласс, Учи.ру, Яндекс.Учебник, SkySmart) и цифровых инструментов (HTML/CSS/JS, GitHub Pages, Google Форма).

**Цель:** сформировать у учащихся представление о растровой и векторной графике, её свойствах, форматах и областях применения.

**Задачи:**
- познакомить с понятиями «пиксель», «векторный объект»;
- научить сравнивать растровые и векторные изображения;
- развивать навыки работы с интерактивными заданиями и цифровыми ресурсами.

**Планируемые результаты:**
- *предметные:* объясняют различия растровой и векторной графики, приводят примеры;
- *метапредметные:* работают по инструкции, анализируют цифровые ресурсы;
- *личностные:* проявляют интерес к цифровым технологиям.

## Как задеплоить

1. Создать репозиторий `multimedia-lesson` на GitHub.
2. Загрузить 4 файла: `index.html`, `style.css`, `script.js`, `README.md`.
3. Settings → Pages → Source: `main` / root → Save.
4. Через 1–2 минуты сайт доступен по адресу `https://ваш-логин.github.io/multimedia-lesson/`.
